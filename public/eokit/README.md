# EOKIT

Дизайн-система админок Korzilla. Плотная, как shadcn (текст 14 px, контролы
24–36 px, волосяные рамки), но цветная: десять тонов с мягкой вуалью. Работает в
обычном HTML: классы `.ui-*`, атрибуты `data-ui-*` и модули поведения на
ES-модулях, без фреймворка и без сборки.

Версия — `version` в `kit.js`, изменения — `CHANGELOG.md`. Как устроен кит и
по каким правилам его менять — `ARCHITECTURE.md`. Как выглядит каждый
компонент — витрина `../showcase/`.

## Подключение

```html
<link rel="preload" href="eokit/fonts/InterVariable.woff2" as="font" type="font/woff2" crossorigin>
<link rel="stylesheet" href="eokit/kit.css">
<body class="ui-root">
```

```js
import { load, mount, unmount, kit, setTheme } from "./eokit/kit.js";
await load(["alert", "select", "popover", "tabs", "tooltip"]);   // icons грузится всегда
kit("alert").show({ title: "Сохранено", type: "success" });
unmount(view); view.innerHTML = next; mount(view);                // перерисовка куска страницы
```

Тёмная тема — класс `dark` на `<html>`; переключать — `setTheme("dark" | "light" | "system")`.
Строки интерфейса кита — русские, есть английские; свои — `setMessages(lang, { "<модуль>.<ключ>": … })`.

### Корзина на витрине

Сайту весь кит не нужен: базовые стили кита (`base.css`) задают шрифт и коробки
всей странице и спорили бы с вёрсткой сайта. Корзина подключает токены, компоненты,
из которых собрана (иконка, кнопка, бейдж, числовое поле, радио), и сама себя;
шрифт она берёт у страницы:

```html
<link rel="stylesheet" href="/eokit/styles/tokens.css">
<link rel="stylesheet" href="/eokit/components/icons/icons.css">
<link rel="stylesheet" href="/eokit/components/button/button.css">
<link rel="stylesheet" href="/eokit/components/badge/badge.css">
<link rel="stylesheet" href="/eokit/components/input/input.css">
<link rel="stylesheet" href="/eokit/components/number-field/number-field.css">
<link rel="stylesheet" href="/eokit/components/choice/choice.css">
<link rel="stylesheet" href="/eokit/components/cart/cart.css">
<script type="module">
  import { load } from "/eokit/kit.js";
  load(["cart"]);   // необязательно: без модуля корзина работает обычными формами
</script>
```

Разметка — в комментарии `components/cart/cart.css`, живой пример — корзина
движка (`modules/site/shop/resources/views/cart.blade.php`).

## Папки

```
kit.css          вход стилей: список файлов в порядке каскада
kit.js           вход JS: каталог модулей, load / mount / unmount / kit(name), setTheme, version
styles/          общие стили: tokens (все значения), base (шрифт, коробки, прокрутка,
                 reduced motion), surface (материал всплывающих панелей), card (карточка
                 таблиц и списков)
components/<имя>/  компонент целиком: <имя>.css, <имя>.js (если есть поведение), подмодули
core/            ядро для модулей: жизненный цикл, слои, позиционирование, вход и уход,
                 фокус, клавиши, жесты, иконки, строки, тема
vendor/          Embla Carousel (MIT); глифы — Lucide (ISC), duo-* — Solar Bold Duotone (480 Design, CC BY 4.0)
fonts/           Inter 4.1 вариативный с opsz (OFL) — основной; Golos Text, Manrope, Onest (OFL) —
                 запасные (--ui-font: var(--ui-font-golos | manrope | onest))
tests/unit/      юнит-тесты ядра: node --test eokit/tests/unit/*.test.mjs
tools/           check (браузерная проверка витрины), lint (правила кита), perf (замеры),
                 build (сборка для выкладки)
```

## Браузеры

Цель — браузеры с середины 2024 года: Chrome и Edge 117+, Safari 17.5+, Firefox 129+.
Ниже цели кит работает, но без части движения. Свойства новее цели
(`interpolate-size`, `field-sizing`) — только улучшение: без них раскрытие идёт
без анимации высоты, поле не растёт по тексту. `tools/lint.mjs` не пускает в кит
то, что новее цели, без запасного вида.

## Выкладка

В репозитории кит работает как есть: `kit.css` подключает стили компонентов
через `@import`, модули грузятся по имени. Это удобно в разработке, но на
медленной сети даёт лишний круг и десятки запросов, поэтому на сервер
выкладывается сборка:

```
node eokit/tools/build.mjs        # → eokit/dist/
```

В `dist/` лежит тот же кит: `kit.css` одним файлом без комментариев (151 КБ,
26 КБ в gzip), а `kit.js` ставит modulepreload всем файлам модуля сразу.
Содержимое `dist/` выкладывается на место папки `eokit/`. Чтобы после
выкладки браузер не смешал новые файлы со старыми из кэша, сервер отдаёт кит
с `Cache-Control: no-cache` (проверка по ETag), либо каждая версия
выкладывается в свою папку (`/eokit/1.0.0/`).

## Как пользоваться компонентами

### Общее

- Тон — одна тройка `--ui-tone` / `--ui-tone-soft` / `--ui-tone-fg` (насыщенный,
  вуаль, текст по вуали), атрибутом `data-tone="green"`; `data-tone="accent"`
  берёт акцент темы. Работает на бейдже, аватаре и коробке 3D-иконки.
- Блоки страницы: `--ui-plate` — серая плашка без рамки на белой панели (поле на
  ней — белое), `--ui-r-2xl` (16) — скругление карточки и плашки.
- Акцент темы — `--ui-accent` (по умолчанию синий): фокус, переключатели, флажки,
  выбор, график; текст и мелкие значки им — `--ui-accent-fg`. Тема Korzilla —
  `<html data-ui-accent="brand">`: акцент — фирменный зелёный `--ui-brand`, текст —
  `--ui-brand-fg`, глубже (светлый зелёный на белом читается плохо).
- Вариант меняет только переменные (`--ui-btn-bg`, `--ui-btn-h`, …): правило
  отрисовки у компонента одно. Пункт меню — та же `.ui-btn`, перенастроенная
  переменными.
- `.ui-btn[hidden]` скрыта, хотя у кнопки свой `display`.
- `.ui-sr-only` прячет элемент с экрана, но оставляет его читалкам.
- Значение, записанное из кода без события, модули видят после `refresh`:
  `kit("select").refresh(select)`, `kit("numberField").refresh(host)`,
  `kit("scaleSlider").refresh(host)`, `kit("checkboxTree").refresh(host)`,
  `kit("editor").refresh(host)`. Сброс формы эти модули видят сами.
- Reduced motion: анимации сжимаются до 1 мс, переходы снимаются; движение,
  которое ведёт JS (стопка тостов, окно, карусель, перетаскивание), не
  запускается.

### Бейдж

Серый, с основным текстом; тон — цветная точка, у статуса — ведущая иконка.
Размеры — как у кнопок: `.ui-badge--xs` 24, `--sm` 28, средний 32, `--lg` 36; отступ,
скругление и текст те же, что у `.ui-btn` того же размера — шаг шкалы контролов
(13 у xs и sm, 14 у md и lg, иконка 14 у xs и 16 дальше). Бейдж рядом с кнопками
берёт их размер.

- `.ui-badge--soft` с `data-tone` — заливка и подпись тоном, без точки; `.ui-badge--outline`
  с тоном — рамка и подпись тоном. Без тона оба — серые, как раньше.
- Двухцветные иконки `duo-*` (`data-ui-icon="duo-medal-star"`) берут тон бейджа.
- Счётчик `.ui-badge--count` — круглый 18; с `data-tone` — заливка тоном.
- Чип-выбор — `<button class="ui-badge" type="button" aria-pressed="false">`, модуль
  `badge` переключает `aria-pressed` и шлёт `badge:change` { pressed }. Выбранный серый
  темнеет, контурный — рамка и заливка тоном, мягкий — сплошной тон. Без ведущей иконки
  у выбранного встаёт галочка; иконка с `.ui-icon--fill` (сердце) заливается.

### Флажок, радио, переключатель

Средние — коробка 16 и свитч 36 × 20 при подписи 14/20. Малые `--sm` — 14 и
30 × 16, подпись 13; крупные флажок и радио `--lg` — коробка 20, подпись
прежняя. Крупного переключателя нет.

### Подсказка под полем

`.ui-hint` — строка под контролом, тон модификатором (`--info`, `--success`,
`--warning`, `--destructive`). У всплывающей подсказки (`tooltip`) — `data-type`
(`success` | `warn` | `error`) на триггере.

### Поповер и меню

- Панель в разметке помечайте `hidden`, чтобы она не мелькала до монтирования.
- Пункт с `data-pick` шлёт `menu:pick` на триггер своего меню (`detail: value,
  item, checked`) и закрывает всю цепочку меню; `data-keep` оставляет меню
  открытым. Из кода — `kit("popover").open(host)` / `close(host)`.
- `role="menuitemcheckbox"` / `"menuitemradio"` с `aria-checked` показывают
  галочку `.ui-popover__check`. `menuitemradio` снимает отметку с соседей по
  `[role="group"]` (без групп — по меню). Поиск над пунктами — `.ui-popover__search`.

### Выпадашка

Тот же поповер с `data-ui-dropdown`. Подпись отмеченного варианта пишет в
`[data-dropdown-value]` кнопки, число отмеченных флажков — в
`[data-dropdown-count]` (ноль прячет), на выбор шлёт `dropdown:change`
(`detail.value`, `detail.values`). Шеврон — `.ui-dropdown__chevron`, приставка —
`.ui-dropdown__prefix`, сплит-кнопка — `.ui-dropdown-split`.

### Селект

- Открытый список уходит в body (в окне — в его слой), закрытый возвращается в
  обёртку: правило «предок → панель» до открытого не достаёт, размер `sm` панель
  несёт сама (`data-size`).
- Список в тексте — `<select class="ui-select ui-select--inline">`: кнопка — само
  слово, шрифт и высота строки — от текста вокруг. Значение выделено (основной
  цвет, 500); тихое свойство в строке списка — `--ui-select-inline-fg` и
  `--ui-select-inline-weight` на предке. `data-size="lg"` — пилюля высотой
  с малую кнопку, как кнопки строки страниц: для фразы в ряду контролов («Показывать по 20»).
- `data-placement="over"` открывает список поверх поля, как в macOS: выбранная
  строка встаёт на место поля.
- Ширина — `--ui-select-w` на любом предке (по умолчанию 240 px). Стрелка
  нативного списка — токен `--ui-select-arrow`.
- С `optgroup` или `data-native` селект остаётся нативным. «Не выбрано» —
  `selectedIndex = -1` из кода: кнопка показывает `data-placeholder` серым.

### Поля

- `.ui-field-row` — ряд полей, который переносится по 140 px.
- Числовое поле понимает только точку: дробное значение покажет как `2.5`. Для
  рублей, штук и процентов берите целый шаг.
- Календарь по умолчанию 240 px (`--ui-datepicker-w`), в теле окна — во всю ширину.

### Выбор цвета

`<input class="ui-input" data-ui-colorpicker value="#e8f1de">` — поле с кодом
цвета и образцом слева; образец открывает палитру: поле насыщенности и яркости,
ползунок тона, пипетка (где браузер её даёт), образцы. Значение — `#rrggbb` в
нижнем регистре; в поле можно вписать hex без решётки, `rgb()`, `hsl()` или имя
цвета — на `change` запись станет hex, неверная вернёт прошлое значение.

- `data-alpha` — ещё и непрозрачность: ползунок в палитре, запись `#rrggbbaa`,
  пока цвет не непрозрачный.
- `data-swatches="#ffffff #18181b #7bbd2e"` — образцы под палитрой, по восемь
  в строке. Необязательное поле получает первым образец «без цвета» (пустое
  значение); с `required` его нет.
- Палитра шлёт `input`, пока цвет тянут, и `change`, когда отпустили, — как
  нативный range. Значение из кода без событий — `kit("colorpicker").set(input, "#fff")`.
- Ширина — `--ui-colorpicker-w` на любом предке (по умолчанию во всю ячейку),
  `data-size="sm"` — компактное поле. Клавиши: стрелки двигают ручку на 1 %
  (тон — на 1°), с Shift — в десять раз дальше, Enter закрывает палитру.

### Поле запроса

`.ui-prompt` с `data-ui-prompt` — вопрос помощнику или поиск словами: поле
`.ui-prompt__area` растёт от `--ui-prompt-min-rows` (1) до `--ui-prompt-rows` строк (6), под ним
`.ui-prompt__bar` — чипы слева, `.ui-prompt__send` справа. Enter — событие
`prompt:submit` (`detail.value`); без `preventDefault` поле пустеет, ↑ в пустом
поле возвращает прошлый запрос. Пока у хоста `aria-busy="true"`, отправка
недоступна. Крестик `.ui-prompt__drop` в чипе шлёт `prompt:drop` и убирает чип.
Текст из кода — `kit("prompt").set(host, text)`. Серый вид — `.ui-prompt--secondary`.

В палитре команд строка с `data-command-query` видна, пока в поле есть текст, и
повторяет его в `.ui-command__query`; `command:select` несёт `detail.query`.

### Загрузка файлов

Очередь — это `files` её `<input type="file">`: форма отправляет очередь как
есть. На каждую правку хост шлёт `file-upload:change` (`detail.files`); из кода —
`kit("fileUpload").files(host)` и `clear(host)`. Подпись «3 файла добавлено» — из
словаря кита, `data-text-count="файл добавлен|файла добавлены|файлов добавлено"`
на хосте важнее. Серый вид — `.ui-file-upload--secondary`.

### Окно

Окно из `<template>` попадает в body уже после старта. Селекты, календари и
кнопки вложенных окон (`data-modal`) в нём ставьте на `modal:open`
(`mount(event.target)`) и снимайте на `modal:closed`.

### Таблицы

- Длины `--ui-table-*` модули читают с хоста при первом замере, поэтому они
  объявлены один раз на `:root` в `tokens.css`. Плотность меняйте до
  монтирования.
- `tableView` и `filterBuilder` ставятся из кода, снимает их `unmount(root)`. О
  правках хосты сообщают событиями: `table-view:sort` (`detail.id`, `detail.dir`;
  из кода — `setSort`/`getSort`), `table-view:select` (`detail.selection`),
  `filter-builder:change` (`detail.value`).
- Условия фильтра — чипы в поле (`.ui-filter-builder--secondary` — серое).
- Матрица «предмет × вариант» — `.ui-table.ui-table--matrix`: подпись строки
  в `<th scope="row">`, на пересечении `<td class="ui-table__choice">` с
  `.ui-check` (или `.ui-radio`) без подписи — дайте флажку `aria-label`
  «строка: столбец». Нажатие в любом месте ячейки переключает флажок.

### Карусель

Двигает Embla: у дорожки и кадров нет своих `transform`, `transition` и
`position`. Просмотр во весь экран (`.ui-carousel-lightbox`) живёт в body, а из
окна — в его слое.

### Дерево разделов

Раскрывается анимацией раскладки. Ставьте его в колонку постоянной высоты
(сайдбар с прокруткой): если от дерева зависит высота страницы, на каждом кадре
раскрытия перерисовывается всё, что ниже.

### Прогресс, спиннер, скелетон, список, свойства

Рисует CSS. Долю прогресса задаёт `--ui-value` (0–100) рядом с `aria-valuenow`;
без `aria-valuenow` полоса неопределённая. Глиф спиннера —
`<span class="ui-spinner ui-spinner--glyph">`. Строку скелетона кладите в тот же
слот, что и текст (`.ui-list__title`, `.ui-list__sub`): при замене на данные
ничего не сдвигается.

### Лента событий

`ol.ui-timeline > li.ui-timeline__item`: знак `.ui-timeline__mark`, текст
`.ui-timeline__body` (`__title` 14/20, `__text` 13/16) и время `__time` справа.
В знаке — иконка 16 цвета тона (`data-tone` на знаке), аватар (станет 20) или
ничего: пустой знак рисует точку. Комментарий — `.ui-timeline__note` в теле;
его заливка полупрозрачная и видна и на белой карточке, и на плашке. Без
`__time` текст занимает всю ширину. Шаг между событиями —
`--ui-timeline-gap` (16).

### Ход работы, «думает», текст ответа

`ol.ui-activity > li.ui-activity__item`: знак `.ui-activity__mark` (круг 24,
иконка 14, `data-tone` — круг тоном) и тело `.ui-activity__body`. Строка шага
`.ui-activity__head`: глагол тише, предмет — в `<b>`; число или время —
`.ui-activity__meta` через точку. `data-state` на пункте: `running` — кольцо
бежит вокруг знака, `pending` — полупрозрачный, `error` — красный. Под строкой
— `.ui-activity__card` (`--stack` — стопка, `data-tone` — полоса слева),
`.ui-activity__quote` или `<details class="ui-activity__group">` с
`<summary class="ui-activity__toggle">` (`__toggle-icon`, `__toggle-label`,
`__chevron`) и вложенным `.ui-activity`; в теле шага к группе идёт ветка от
линии. `data-enter` — пункт въезжает. `--sm` — знак 20, текст 13.

`.ui-thinking` (`role="status"`): `__mark` со знаком помощника — кольцо бежит,
знак дышит; `__label` — что делает сейчас, блик по тексту, новая подпись
(замена узла) въезжает; `__meta` — сколько прошло; `__dots` вместо подписи.
Тон кольца — `--ui-thinking-tone` (`--ui-ai`).

`.ui-prose` — обёртка готовой разметки: `p`, `h2–h4`, `ul/ol` (вложенные),
`blockquote`, `code`, `kbd`, `mark`, `hr`, таблица в `.ui-prose__table`
(`data-align="end"` у числовой ячейки). Блок кода — `.ui-codeblock` →
`__head` (`__lang`, кнопка `.ui-codeblock__copy` с двумя иконками: копировать
и галочка) и `<pre><code>`. Модуль `prose` копирует текст `pre`, ставит кнопке
`data-copied` на 1,5 с и шлёт `prose:copy` (`detail.text`, `detail.ok`).

### График

`figure.ui-chart` с `data-ui-chart` и данными в `<script type="application/json">`:
`x` — даты ISO по дням, `series` — ряды `{ name, values, x?, compare?, tone? }`.
Первый ряд — линия акцента с заливкой, `compare: true` — пунктир прошлого
периода со своими датами в `x`; подсказка показывает оба дня. `format` —
параметры `Intl.NumberFormat`, `unit` — слово при числе (`заказ|заказа|заказов`),
`zero: false` — ось по размаху значений без заливки (средний чек, доля),
`legend: false` — без легенды. Новые данные — `kit("chart").update(host, data)`.
Высота поля — `--ui-chart-h` (200). На плашке ставьте
`--ui-chart-bg: var(--ui-plate)`: кольцо точки берёт цвет подложки.

Вкладки-показатели — `.ui-tabs.ui-tabs--stat`: в табе `.ui-tabs__label` и
`.ui-tabs__value` (число, рядом бейдж разницы), в панели — график показателя.

Длинная лента вкладок листается стрелками у краёв — их ставит модуль, видны
они, только пока в свою сторону есть скрытые вкладки. Под стрелкой — цвет
`--ui-tabs-under` (по умолчанию `--ui-surface`): ленте на другом фоне задайте свой.

### Перетаскивание

Модуль сам ставит `is-branch` пункту дерева со своим списком и
`is-drop-target` — корню и пункту, в чей список встанет перетаскиваемое.
