# Korzilla 996

Внутренний портал компании Korzilla на замену Битрикс24: сотрудники и отделы,
CRM-сделки с воронками, задачи, бизнес-процессы, уведомления.

Ветка `korzilla-996` живёт отдельно от CMS korzillaX: своя история, кода CMS нет.

## Что внутри

```
public/eokit/   дизайн-система EOKIT (копия frontend/eokit из ветки Kirye)
public/app/     оболочка admin2 и модули портала
  modules/portal/   обзор, сделки (канбан), задачи, сотрудники, бизнес-процессы
                    data.js — демо-данные до появления сервера
```

Сейчас это статическое приложение без сборки: открыть `public/` любым
веб-сервером, например `python3 -m http.server -d public 8996`, и зайти
на `http://localhost:8996/`.

## Дальше
