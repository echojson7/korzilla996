# Правила для Claude

- Это Korzilla 996 — внутренний портал компании, не CMS. Код CMS korzillaX сюда
  не переносить. Работать только в ветке `main`, пушить прямо в неё; других веток не создавать.
- Внешний вид — только кит EOKIT (`public/eokit`) и оболочка admin2
  (`public/app`): компоненты кита, без своих кнопок и размеров. Не хватает
  кита — расширять кит.
- Новые тексты — только по-русски. Ширина страницы — полем `width` манифеста
  (`wide` или `narrow`).
- Модули портала — `public/app/modules/<модуль>/module.js`, слой подключается
  в `public/app/sites/layers.js` и `sites/index.js`.
- Сервер — Laravel 13 в корне ветки. Приложение ходит в API по адресу
  `../index.php/api/…` от страницы (`public/app/js/data/api.js`): на стенде
  подпапка `/996/` без `index.php` в адресе уходит в Laravel стенда korzillaX.
- Учётки сотрудников заводит только консоль (`staff:create`), регистрации нет.
